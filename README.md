# Tres Amigos, Una Vida — Superman Rebuild

This package replaces the current GitHub Pages website.

## Included
- Desktop and mobile layouts for every public page
- Responsive menu with no JavaScript dependency
- Cache-busted stylesheet reference
- Homepage, book, author, press, store, and 404 pages
- Amazon, Etsy, and Shopify buying links
- SEO metadata, canonical URLs, Open Graph, Twitter cards, and schema
- robots.txt and sitemap.xml
- CNAME and .nojekyll for GitHub Pages
- No seo.html file

## Upload
Replace the current repository root files with the contents of this ZIP. Keep the folder structure exactly as provided.

After GitHub Pages deploys, hard-refresh Safari:
Command + Option + R

The stylesheet URL contains a version query so the broken cached CSS should no longer be reused.
